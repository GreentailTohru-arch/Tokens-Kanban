# Assets

This directory stores reusable fonts, images, music, and sound effects, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

Codex Token Display uses `fonts/NotoSansCJKsc-Regular.otf` from
[Noto CJK](https://github.com/notofonts/noto-cjk), licensed under the included
`fonts/OFL.txt`. `tools/token_font.py` generates the 14px PLAIN 4bpp
`fonts/token_font_14.c` and a Unicode/hash inventory. Only the generated subset
is linked into the firmware; the full OTF is a reproducible source asset.
See [application documentation](../docs/codex-token-display.md) for verification.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

## Music and sound effects

The user-supplied `images/codex-details-reference.png` and
`images/codex-analytics-reference.png` are retained unchanged as local design
references for the Codex application, not embedded in firmware. Source: user
attachments, 2026-10-16; redistribution license unspecified. Postcard photos/QRs
are runtime imports, not embedded or saved in the source repository.

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.

- `images/postcard-date-reference.png`: user-supplied date/weekday header reference (2026-10-16); reference only, not embedded in firmware; license unspecified.

- `images/postcard-default-avatar.svg` / `.png`: original symmetric default avatar (MIT), generated by `tools/create_default_avatar.py` and bundled in the web editor. The earlier supplied reference is retained as `images/postcard-avatar-reference.png` and is not the default asset.
- `images/postcard-editor-header-reference.png`: supplied previous editor header, retained as redesign reference only.
- `images/postcard_default_rgb565.c`: generated with `tools/postcard_defaults.py` from the actual editor; flash-only fallback faces, including the public editor URL QR.
