# 虚拟宠物按键

通过 Windows 同步程序打开设备管理 → 虚拟宠物，修改按键后点击“保存宠物按键”或顶部保存。按键经 USB／蓝牙同步连接传递，需要同步程序运行；设备不是蓝牙键盘。

| 按键 | 单击 | 双击 | 三击 | 长按 |
| --- | --- | --- | --- | --- |
| 上 | 发送消息 | 撤销输入 | 停止／继续 | 调高音量 |
| 下 | 无 | 自定义快捷键（未设置时无操作） | 无 | 调低音量 |
| OK | 无 | 下一开启页面 | 上一开启页面 | 听写 |

v32 起，所有页面的 OK 双击／三击按已开启页面顺序循环翻页，不可自定义。宠物页提供七个可自定义点击手势及一个听写开关；上下长按保留音量。单击和双击等待松开后 350 毫秒，以区分三击。网页模拟只展示反馈，不控制电脑。其他页面的单击 OK 保留原功能。

## 自定义快捷键与保存

在对应手势选择“自定义快捷键”，打开完整键盘弹窗点选单键或组合键，确认后显示组合。再次点选取消，支持最多四键、其中最多一个普通键；窄屏可横向滚动。已有组合可在同一下拉菜单选择“调整快捷键…”。没有直接录入和独立的“保存本机快捷键”按钮。

点击“保存宠物按键”或顶部保存，先保存修改过的电脑快捷键，再保存设备映射。电脑保存失败时不写设备；设备保存失败时提示电脑部分已保存，可重试。每个手势独立，清空只禁用该手势，不影响其他手势和听写。公开网站可预览，不能保存电脑配置。快捷键作用于前台应用，应用是否接受模拟输入需实际测试。

运行同步程序并聚焦目标 Codex 输入框后，可发送、撤销、停止与继续；再次继续在空输入框发送“继续”，不覆盖草稿。原左右 Alt 应用快照因无法可靠触发，已改为自定义快捷键。

## 听写

将 Codex 的“听写快捷键（按住）”与 `%LOCALAPPDATA%/TokensKanban/pet-controls.json` 的 `dictation_hotkey` 设为相同组合，例如 Alt+H。未配置时程序默认 Ctrl+Alt+F9；升级保留本机配置。允许电脑麦克风后，在宠物页按住 OK 录音，松开保留文字，不自动发送。动画表示快捷键按下状态，不代表检测到了声音。切换到其他应用、连接超过 1.5 秒无响应、退出或按住达到 20 秒都会释放按键。

MacOS 同步包提供数据同步，本版电脑遥控仅支持 Windows。

## 协议与兼容

`PC_KEYS_GET` 返回 `PC_KEYS 2` 与九个操作编号，保留旧存储布局。索引 7 原 OK 三击槽位保留为 0，不再编辑或触发；其余配置不变。自定义操作 16～22 对应七个点击槽位；旧操作 4 和旧电脑配置仍兼容。`PC_KEYS_SET id ...` 经 `PC_CFG_STATUS` 工作任务保存。

`PC_CTRL_POLL session ack` 返回 `PC_CTRL 1 sequence action held`。新连接丢弃待执行动作，1.5 秒过期，执行前去重。离线动作不积存重放。主机检查覆盖点击时序、翻页顺序、保存失败、去重和听写释放；本版固件不自动刷入，实体按键手感由用户测试。
