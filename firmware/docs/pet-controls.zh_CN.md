# 宠物页按键

v26 宠物遥控固件与对应 Windows 同步程序为 Codex 宠物页增加遥控功能。
其他页面保持原操作。按键经过现有 USB／蓝牙同步连接传递，需要电脑同步程序，
不是蓝牙键盘模式。

| 按键 | 单击 | 双击 | 三击 | 长按 |
| --- | --- | --- | --- | --- |
| 上 | 发送消息 | 撤销输入 | 停止／继续 | 调高音量 |
| 下 | 无 | Codex 窗口截图 | 无 | 调低音量 |
| OK | 无 | 下一开启页面 | 无 | 语音输入 |

设备管理 → 设置 → 宠物按键，可修改九项映射、恢复默认并保存到设备。
双击 OK 和长按上下保留。单击和双击等待松开后 350 毫秒，以区分三击。
网页预览只模拟反馈，不会控制电脑。

运行对应 Windows 同步程序；发送、撤销、停止与继续前，让目标 Codex 输入框
位于前台。成功停止后再次触发，会在空输入框中输入并发送“继续”，不覆盖草稿。
发送、撤销、停止使用 Windows 辅助功能控件；识别不到控件就报告失败，不执行。
当前安装的 Codex 在只读检查中没有暴露输入控件，这三项须经电脑验收后才能发布。
兼容测试时，先保存工作并完全退出 Codex，再从启动菜单选择 5，以开启渲染器辅助访问的
参数打开已安装的 Windows Codex。该操作不会关闭现有会话；重新打开后仍须验证是否
兼容。它不会修改 Codex 的自动启动偏好。

在 Codex 设置 → 键盘快捷键，将**听写快捷键（按住）**设为 Ctrl+Alt+F9，
并允许麦克风。长按 OK 使用电脑麦克风，松开结束听写，不自动发送。
同步程序按住快捷键时显示聆听动画；它表示快捷键状态，不代表已测得麦克风正在录音。
实际录音、转写仍受 Codex 权限和可用性约束。切走窗口、连接超过 1.5 秒无响应、
退出或连续按住达到 20 秒，都会释放注入的按键。

窗口截图同时按下左右 Alt，由 Codex 自己按权限和所选目的聊天捕获前台窗口，
不会额外发送 Enter。请在 Codex 中把 Appshot 目的地设置为需要的聊天。

macOS 同步包保持数据同步；本版电脑遥控仅支持 Windows。
不新增 Wi-Fi、录音上传、API 密钥或额外的固件动画缓冲区。

## 协议和验收

`PC_KEYS_GET` 返回 `PC_KEYS 1` 与九个操作编号；`PC_KEYS_SET id ...`
使用现有 `PC_CFG_STATUS` 工作任务保存流程。操作 0～4 分别为无、发送、撤销、
停止／继续、窗口截图；长按项只能为 0 或 5（听写）。

`PC_CTRL_HELLO` 协商支持；`PC_CTRL_POLL session ack` 返回
`PC_CTRL 1 sequence action held`。同步程序在普通五秒数据同步之间每 100 毫秒读取一次。
新会话或切换连接丢弃待执行操作；操作 1.5 秒失效，执行前去重，失败也不重放。
离线按键不会积存到下次连接。

主机检查覆盖手势、保留按键、保存失败、过期会话、去重、录音释放和网页预览。
实体按键时序、实际 Codex 输入框、窗口截图、麦克风权限和转写仍需实机及电脑验收。
