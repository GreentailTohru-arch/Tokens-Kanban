# Tokens Kanban v22 连接使用

v20 移除设备 Wi-Fi、配网热点、局域网发现和设备内置网站。保留 USB、蓝牙、
四个页面、页面及卡片管理、明信片、用户音效、音量、亮度和开机设置。
保留主任务栈修复，不擦除原用户数据分区。

1. 完整解压 Windows 包，运行 `start-auto.cmd`，保持程序运行以同步本机 Codex
   和 TrafficMonitor 数据。自动模式先尝试 USB，再尝试蓝牙；
   `start-bluetooth.cmd` 仅用蓝牙。桥接 DLL 未变，已有 TrafficMonitor 不必重启。
2. 连接成功后自动打开电脑本机管理网页，与同步程序共用同一条 USB／蓝牙连接。
   不要让其他网页抢占程序正在使用的端口。关闭程序后，仍可使用浏览器直接通过
   USB 或蓝牙管理设备。
3. 单击确定显示明细或联系方式，双击循环已启用页面。上下键保留原行为；
   长按上下调节音量，确定关闭音量条且不翻页。长按确定不再打开配网界面。
4. 网页可读取和保存设置、页面及卡片顺序、明信片和开机 Logo。
   联系二维码仍是用户图片；默认的公开网页链接不负责手机配对或采集电脑数据。

管理服务只监听电脑 `127.0.0.1`。这一 HTTP 代理不代表设备仍支持 Wi-Fi；
它保留访问校验、手动断开及重连、自动打开网页和重复启动复用。
`--no-browser` 可关闭自动打开。

设备页面直接切换，仅音量条保留右侧滑入和收起效果。管理网站使用短促的侧栏和弹窗动画，并遵循系统减少动态效果设置。普通通知约 2.2 秒、错误约 4.2 秒，可滑走、点关闭按钮或按 Esc 关闭；鼠标悬停或键盘聚焦时暂停计时。内容、设备设置与用户开机 Logo／GIF 和音效保持原样。实际续航变化尚未测量。
打开网站会自动检查 GitHub 最新正式版本，连接设备后读取固件版本并比较。点击顶部版本标记进入“关于”，安装仍需手动操作；设备高于公开版时会明确说明，不提供降级。检查失败会显示暂不可用，可手动重试。发布版本缺少有效安装清单时仍可识别版本，但不能通过网页安装。

体验模拟使用用户提供的透明背景实机正面图，交互画布对齐照片屏幕，四个控件对应实物按键位置；屏幕内容仍明确标注为示例数据。

独立“主题”页面控制设备配色：默认（原始蓝灰）、黑曜、瓷白和绿色 ASCII。高级自定义可折叠，支持强调色、图表色、背景、文字、次要文字以及单项／整套恢复。右侧实机外观预览复用体验模拟器，支持电源、上下和确定键的单击、双击、长按；数据明确为示例。连接 v21 设备后读取真实配色，点击顶部“保存到设备”并读回校验后生效，重启保留。旧固件仅预览，提示升级；未保存的配色纳入离开提醒。v22 的明信片背景、标题及联系方式文字随主题变化；头像、二维码和开机图片保留原色，已保存的明信片数据不会重写。页面管理缩略图和明信片预览使用当前设备配色。状态灯颜色仍表达真实状态。

网站自身使用独立的 WinUI 风格，左侧栏最下方切换日间／夜间并按浏览器来源记忆；切换设备主题不会改变网站颜色，切换网站日夜也不会写入设备。


v22 取消管理页面下移淡入，模拟屏幕每次只提交完整画面；音量条保留右侧滑出。实机没有切页补间动画，将单个 DMA 刷新缓冲从 4 行增至 20 行（增加 7680 字节，整屏分段从 80 次降为 16 次），减轻逐块刷新感；实际观感和运行余量仍需刷入后验证，不宣称液晶传输完全无扫描。网站标签图标、侧栏和关于页使用用户提供的黑／白 TK 图片，并随网页日夜模式切换；开机 Logo 保持原样。

屏幕检测恢复黑、红、绿、蓝、白按钮的真实色样，并加入彩条与 16 阶灰度示意预览。连接 v22 可在实机显示对应图案，按任意键或约 15 秒后退出；旧版设备仍可纯色检测，彩条和灰度会提示升级。测试图案不受设备主题或网页日夜模式染色。
