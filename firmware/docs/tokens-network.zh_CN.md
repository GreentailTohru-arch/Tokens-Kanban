# Tokens Kanban v19 连接使用

## 电脑开始使用

1. 完整解压 Windows 包，运行 `start-auto.cmd`。Codex 与 TrafficMonitor 数据需要此程序持续运行；它依次优先 USB、已配对 Wi-Fi、蓝牙。手机管理网页不采集电脑数据。
2. 连接成功自动打开本机管理页，管理与同步共用同一条连接，包括单连接蓝牙。不要再从线上网页抢占正在使用的串口或蓝牙。反复重连时每分钟最多打开一次网页；`--no-browser` 可关闭自动打开。
3. 设置 → Wi-Fi，通过 USB 填写 **2.4 GHz** 网络名称、密码，点“保存并自动连接”。开放网络密码留空；暂不支持企业认证。网络保存在设备，开机和临时断线后自动重连，不上传 GitHub。
4. 联网成功后让 USB／蓝牙再保持至少一轮同步。电脑把配对令牌与地址保存在仓库外 `%LOCALAPPDATA%/TokensKanban/network-devices.json`；拔线后可发现同一局域网内已配对的设备。`start-wifi.cmd` 仅用 Wi-Fi，`--wifi-host IPv4` 指定某个已配对设备。地址变化会重新发现；未配对设备先连接一次 USB／蓝牙。访客隔离或防火墙可能阻止局域网发现、HTTP 访问。

## 手机配网与管理

长按设备**确定键**显示管理二维码；上下键切到配网，开启有效十分钟的加密热点。手机扫描 Wi-Fi 二维码加入热点。系统可能自动弹出设置窗口；未弹出时，在浏览器打开 `http://192.168.4.1/`。进入设置 → Wi-Fi 填写家中网络。切换网络时网页可能中断：手机加入同一家中 Wi-Fi，再扫描设备管理二维码。短按确定关闭浮层，不翻页。

联网后的管理二维码指向设备自带网站，并包含管理令牌，请勿公开。普通蓝牙连接不传 Wi-Fi 密码：先开启热点，再用手机配网，或改用 USB。不需要额外手机应用、云中转或 LibreHardwareMonitor。手机的小型配网窗口功能受系统限制时，可改用完整浏览器。

设备被动 NTAG213 标签支持 NDEF 网址。可用支持 NFC 写入的手机一次写入公开管理地址 `https://greentailtohru-arch.github.io/Tokens-Kanban/`，以后贴近并点击提示进入网站。NFC 不会自动完成 Wi-Fi／蓝牙连接。MCU 没有标签写入接口，固件不能更新标签地址；变化的局域网管理地址仍用屏幕二维码。

## 保留的操作与数据

双击确定仍按保存顺序循环开启页面；短按上下切换原周期，长按调音量。二维码浮层不改变页面配置。设备设置、明信片、开机 Logo 和用户提供的声音保留原分区，Wi-Fi 使用独立 NVS 命名空间，无需全片擦除。

网页体验模拟的左侧电源键支持单击熄屏／唤醒，长按两秒关闭、半秒启动；唤醒操作会被消费。实机独立电源键由硬件控制，当前 BSP 未提供其单击事件，因此本次不声称实现了新的实机电源单击行为；真实设备自动熄屏后仍可用原有三个功能键唤醒。

设备本地管理网页使用 HTTP；GIF 导入包含本地解码器，不依赖 `ImageDecoder`，仍按原限制取景、压缩。固件安装仍需桌面 Chrome／Edge、Web Serial、USB，以及 HTTPS 线上页或本机管理页；手机／设备 HTTP 网页可管理和下载，不能绕过这些安装要求。

## 兼容与验证边界

新电脑代理兼容 v18：Wi-Fi 不支持时明确提示，不影响 Token 和系统数据同步。线上网页直接 USB 连接保留先释放 RTS、再释放 DTR 的顺序；经电脑代理管理不再打开第二条物理连接。

电脑测试覆盖命令／密码长度、重连间隔、异常 DNS、配对缓存、认证局域网发现、HTTP 授权、网页重连、二维码识别、原设置和手机布局。编译成功不代表 Wi-Fi 实机通过；开机重连、实际局域网、手机自动弹窗、无线共存、长期内存与 NFC 写入，需明确同意刷入后再验证。
