# Codex 宠物页（v26）

第五个设备页面：左上角 Codex 状态、右上角电量，中央播放作者提供的六张透明 GIF。
双击确定键切到此页，可在管理网页的“页面管理”开关、排序。
体验模拟提供六种示例状态，不将示例状态写入设备。设备主题改变背景，不改变宠物原色。

增强状态需要 v26 同步程序。统计连接有效时显示在线；任务进行时显示思考；
任务完成后直接恢复在线。近期尚未结束的终端或支持的电脑／浏览器
工具调用显示使用电脑。有效额度确已耗尽时优先显示额度不够，缺失或过期数据不算耗尽。
连续十五秒没有统计同步后显示未连接。

已内置“正在听你说话／看你打字”动画并可预览，但当前 Codex 日志没有可靠的
实时麦克风或发送前打字信号，因此不自动猜测触发。电脑操作仅根据本地会话中
明确的工具名称识别；嵌套或未上报的操作仍显示思考。本功能不保存对话、工具参数或录音。

固件提供可选 `PC_PET_HELLO`、`PC_PET <序号> <状态>` 协议，状态 0～5 对应
所给图片顺序。旧同步程序仍可从用量状态推导基本动画。
五页配置使用 `PC_PAGES_GET2/SET2`，旧四页的顺序和开关完整迁移，末尾新增宠物页。
旧网页继续使用四页协议，不会清除宠物页设置。

共三十八帧，保留原 GIF 帧时长、透明背景和 192×208 分辨率。
转为 RGB565 逐行压缩后约占 850 KiB Flash，仅解码一行，不分配整张 GIF 缓冲区。
宠物控件仅在该页存在，离开页面或熄屏后停止动画更新。
开机 Logo 与音量条滑出逻辑保持不变；实机验收需另行授权刷入。

左上角状态文案与用量首页统一：待命中、运行中（思考）、操作中（使用电脑）、额度不足、听写中；断开连接仍显示“未连接”。
