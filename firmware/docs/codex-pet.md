# Codex pet page (v33)

The pet page displays Codex status, battery level and one of three animations.
Double-press OK for the next page or triple-press for the previous page.
Use Page Management to enable or reorder the pet page.

| Displayed status | Animation |
| --- | --- |
| Disconnected | Quota exhausted |
| Idle | Online |
| Running | Thinking |
| Quota exhausted | Quota exhausted |

The pet returns to idle when a turn completes. Terminal and browser operations
are part of the running state. A fresh exhausted quota takes precedence while
connected. The web simulator previews all four statuses.
