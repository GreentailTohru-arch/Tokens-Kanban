# 电脑端自动连接

完整解压电脑程序包，运行 `start.cmd`，选择“启动同步”。同一入口也可开启／关闭
当前用户的 Windows 登录启动，或停止后台同步。开机启动需要用户选择开启，
会在当前用户的启动文件夹创建本程序的快捷方式，无需管理员权限；登录后
隐藏运行，不自动弹出浏览器。请保留解压目录，移动目录后需在新位置重新开启。
关闭开机启动不会停止当前进程，需要停止时选择“停止后台同步”。更换程序前
需停止旧版；旧版不支持停止命令时，在原窗口按 Ctrl+C 或用任务管理器退出。

同一个进程发送 Token 和 TrafficMonitor
数据：自动模式优先 USB，没有 USB 或串口不可用时尝试蓝牙；蓝牙连接期间发现
USB 后会尝试切回。先完成 USB 握手，再关闭原蓝牙连接。不可用的 USB 端口
间隔 30 秒重试；拔掉该端口后清除重试等待。

切换不是零间隔：程序在五秒同步周期内检查，蓝牙扫描、握手和系统重试可能
需要更久。网页写入和上传状态请求会将主动切换延后至五秒无操作后；只读的
设备信息轮询不延后切换。保存期间请勿拔线。

每个用户只运行一个发送进程。操作系统锁防止同时启动多个进程，退出或异常
结束后会释放。重复启动复用管理网页，不会替换已有进程或改变其连接模式。
更新前先停止旧程序。`start-auto.cmd` 保留为等效的旧入口，
`start-bluetooth.cmd` 保留为仅蓝牙入口；切换模式需要先停止再重新启动。

自动选择适用于一台 AI Passport。多个 USB 设备需用 `--port` 指定；多个蓝牙
设备需用 `--ble-address` 指定。指定蓝牙地址后，不主动切换到无法核实身份的
USB 设备。此次不修改 TrafficMonitor、固件、设备设置、图片存储或音效，
也不会自动启用 Windows 开机启动。刷机期间仍需停止同步程序。
