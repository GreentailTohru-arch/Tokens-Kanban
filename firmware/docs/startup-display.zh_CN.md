# 开机显示修复（v24）

## 整屏取景（v25）

网页取景器以整块 240×320 屏幕为 3:4 取景范围。导入后默认完整显示图片，
支持 10%～800% 缩放与拖动，既可缩小留黑边，也可放大裁切。GIF 所有帧使用
相同位置。原默认 Logo 保留；确认取景后单独保存开机 Logo。

TLG2 存储有界的 3:4 画面（最大 120×160），显示解码器逐行扩展至 240×320，
避免分配整屏变换缓冲区。复杂 GIF 会按现有存储上限适当降低分辨率或帧数。
旧 TLG1 正方形 Logo 继续按原大小居中显示。网页通过 `PC_LOGO_CAPS` 检查
新格式支持情况，旧固件可预览但不能保存新格式。现有设置及图片分区不变。

主机／浏览器检查覆盖竖版解析、旧格式兼容、完整适配、缩小、放大、位置保持、
GIF 解码及网页实际输出文件的固件解析。真实 LVGL 渲染检查覆盖整屏边缘，
并在 48KB 图形内存池中验证重复界面更新。实机验收待执行。

读取已保存设置和开机图片期间保持背光关闭。选定首帧、完成绘制并等待 SPI
像素传输结束后，才应用保存的屏幕亮度。有效的自定义图片在屏幕点亮前替换
默认 Logo；没有自定义图片或数据无效时保留原来的默认 Logo。动画仅播放一遍，
等待开机音效结束期间停留在最后一帧。不重写已保存的图片、声音和设置。

左侧独立电源键控制硬件供电。现有 BSP 只提供右侧三个 ADC 按键，没有电源键
短按的软件事件接口，因此不能承诺通过固件实现该键短按熄屏。自动熄屏仍可用。

主机回归测试覆盖帧边界以及动画结束后停留在最后一帧。冷启动、重启、自定义
静态图／GIF 替换和可见闪烁仍需实机验证。刷入固件和公开发布需另行授权。
